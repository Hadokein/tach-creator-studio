Вход через Tach

Подключи свой аккаунт Tach по телефону. Код подтверждения обрабатывается сервером Creator Studio и Tach; токены не показываются в браузере.

Гостевая аналитика продолжит работать без входа.

Экспериментальная интеграция. Вход может не сработать, если Tach ограничит сторонние приложения. Повторный вход понадобится после истечения токена. Не используй вход на чужом устройстве.

Прирост просмотров по дням

Прирост рассчитывается отдельно для каждой публикации. При пропусках измерений рост относится ко всему промежутку и показывается в дату следующего замера.
