Tach Creator Studio 4.2

Замените index.html, app.py, requirements.txt в GitHub, затем дождитесь Render deploy.

Новый раздел «Активность по уведомлениям» читает /api/v1/push-service/notifications/ после успешного входа через Tach и только для вошедшего владельца профиля. Если Tach запрещает сторонний вход (403), этот раздел останется недоступен; публичная аналитика продолжит работать.

Важно: timestamps created отражают время уведомлений, а не обязательно все просмотры, лайки и комментарии. Сервер не получает точные даты всех просмотров. Данные уведомлений не следует суммировать с публичными счётчиками.

Автосбор общих публичных счётчиков по /api/analytics/cron уже существует, но требуется внешний cron с CRON_SECRET; Render Free может засыпать. Уведомления по cron не собираются: для них нужна авторизованная сессия пользователя, а токен истекает.

SQLite на Render Free без постоянного диска не сохраняется гарантированно между деплоями.
