Tach Creator Studio 3.6 — экспериментальная авторизация через Tach
==============================================================

Содержимое:
  app.py            Flask API, guest-аналитика, публичные профили, модуль Tach Auth
  index.html        полный адаптивный интерфейс с встроенным логотипом
  requirements.txt  Flask, Requests, Gunicorn, cryptography

Установка на Render/GitHub:
1. Замените app.py, index.html, requirements.txt файлами из архива.
2. В Render -> Environment добавьте TACH_AUTH_SECRET со случайной длинной
   строкой (не менее 32 символов, рекомендуется 48–64). Можно использовать
   функцию Generate на Render. НЕ добавляйте секрет в GitHub или HTML.
3. Если у вас подключён постоянный диск Render, укажите TACH_AUTH_DB
   (например, /var/data/tach_auth_sessions.sqlite3). На временном диске
   авторизация теряется при перезапуске/деплое.
4. Сохраните настройки и дождитесь штатного деплоя. В интерфейсе откройте
   «Войти через Tach». Для авторизации понадобится подтверждение номера.

Механика:
  POST /api/tach-auth/start -> POST /auth/signinup/code на api.id.hublab.ru
  POST /api/tach-auth/verify -> POST /auth/signinup/code/consume
  GET  /api/tach-auth/me -> статус сеанса (без токенов)
  GET  /api/tach-auth/check -> авторизованная проверка API Tach
  POST /api/tach-auth/logout -> локальное завершение сеанса

При просмотре собственного профиля в аналитике сервер отправляет личный
Bearer access-токен. Для других профилей используется гостевой токен.
Access-токен хранится только шифрованным на сервере. Refresh-токен не
сохраняется: после истечения сессии нужно войти снова. Cookies HttpOnly,
Secure, SameSite=Strict. Есть ограничение частоты запросов и попыток кода.

ВАЖНО — эксперимент:
- Мы не проверяли авторизацию end-to-end на живом API Tach: Tach может
  потребовать дополнительные параметры или заблокировать сторонний клиент.
- Наличие протокола API не равно разрешению Tach сторонним приложениям.
- Запрос SMS/звонка зависит от поведения серверов Tach; поддержка кнопок
  выбора способа в текущем эксперименте не реализована.
- Для публичного многопользовательского продакшена нужны отдельные
  независимые аккаунты Creator Studio, антиспам, мониторинг, аудит
  безопасности и официальное разрешение/интеграция Tach.
- Не размещайте ключи и токены от Tach в репозитории, issue или чате.
- Ранее раскрытые refresh/access-токены и ключ стрима необходимо отозвать.
